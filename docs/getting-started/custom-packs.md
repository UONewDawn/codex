# Custom Packs

Custom packs change how the game looks and sounds. They're optional and only affect your own client.

## Installing a pack

1. Close the game.
2. Download the pack below.
3. Extract the zip directly into your New Dawn game folder (the one containing `ClassicUO.exe`) and allow it to replace files. The files land in `Data/Custom`, as described in [Custom Art & Gumps](client-customizations.md).
4. Start the game.

## Removing a pack

Each pack lists the files it replaces under **Files and checksum**. Delete those files from your game folder and the game goes back to its normal art.

!!! warning "Packs that replace the same files"
    Some packs replace the same files. If two packs conflict, the one you extracted last wins.
