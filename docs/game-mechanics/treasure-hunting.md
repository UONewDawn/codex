# Treasure Hunting

Treasure Hunting is all about following a decoded map to its marked spot, digging up a buried chest, fighting off the creatures that rise to defend it, and claiming the gold and loot hidden beneath the soil.

## Template

These are the core skills:

- Cartography
- Lockpicking
- Magery

This is a suggested template:

- Magery
- Meditation
- Cartography
- Lockpicking
- Mining
- Item identification
- Hiding / Resisting spells

That can also work for [Mining](../skills/resource-gathering/mining.md) and [Archaeology](../custom-systems/archaeology.md).

### From Fishing

Sea Serpents pulled up while fishing have a chance of dropping a Level 1 map.

Sea Serpents pulled up using fishing nets have a rare chance of dropping a Level 2 map.

For more information visit the [Fishing](../skills/resource-gathering/fishing.md) page.

### From Pirate Adventures

The reward chest from [Pirate Adventures](../custom-systems/pirate-adventures.md) can contain multiple maps from level 1 to 6.

## Decoding the map

Decoding the map requires Cartography.

Only the player that has decoded the map will be able to dig up the treasure.

This table shows the skill level required to attempt decoding.

| Map Level | Skill Level |
|:---------:|:-----------:|
|  Level 1  |      0      |
|  Level 2  |     60      |
|  Level 3  |     73      |
|  Level 4  |     91      |
|  Level 5  |     99      |
|  Level 6  |    99.2     |

Once decoded, the map description will show the location number.

## Monster spawns

For Level 1 maps, monsters will start spawning once you begin looting the treasure chest.

For all other levels, monsters will spawn as soon as you dig up the chest, and will continue to spawn every time you loot something from it.

For higher level maps, this can be used to your advantage, loot one gold piece at a time to force a spawn and gain additional loot from the monsters.

| Map level |                               Spawn                                |
|:---------:|:------------------------------------------------------------------:|
|  Level 1  |        Skeletons, Zombies, Headless Ones, Ratmen, Mongbats         |
|  Level 2  |    Earth Elementals, Gargoyles, Gazers, Hell Hounds, Orc Mages     |
|  Level 3  | Fire Elementals, Air Elementals, Liches, Ogre Lords, Dread Spiders |
|  Level 4  |          Elder Gazers, Dread Spiders, Lich Lords, Daemons          |
|  Level 5  |      Poison Elementals, Lich Lords, Blood Elementals, Daemons      |
|  Level 6  |          Ancient Wyrms, Blood Elementals, Balrons, Titans          |

## Treasure chest

### Digging up the chest

You will need to stand one tile next the coordinates and have a shovel with you.

To dig up the chest, use the shovel and target the map, or single-click the map and choose the "Dig For Treasure" option.

### Unlocking the chest

Level 1 and 2 maps can be opened by using the Unlock spell with enough Magery.

For all other levels, Lockpicking is required.

| Map level | Lockpicking skill | Magery skill |
|:---------:|:-----------------:|:------------:|
|  Level 1  |        35         |      50      |
|  Level 2  |        77         |     100      |
|  Level 3  |        80         |      -       |
|  Level 4  |        95         |      -       |
|  Level 5  |        100        |      -       |
|  Level 6  |        100        |      -       |

### Dealing with the trap

For Level 1, 2, and 3 maps, you can safely tank the trap damage as it will not be fatal.

You can also use the spell Remove Trap or Telekinesis from 8 tiles away to avoid damage.
